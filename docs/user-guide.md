# 使用文档

本页面面向测试、联调和产品验证，目标是让你在最短路径内把当前项目跑起来。

## 运行前准备

- 安装 Node.js
- 安装 Android Studio
- 准备一台 Android 模拟器或真机
- 真机联调时，手机和电脑需要在同一局域网

## 启动后端

在仓库根目录执行：

```bash
cd server
npm install
npm run dev
```

启动后可以先检查两个接口：

```text
GET http://localhost:3000/health
GET http://localhost:3000/config
```

如果使用真机，请把 `localhost` 换成宿主机局域网 IP。

## 运行主应用

1. 使用 Android Studio 打开 `clients/android/mainproject`
2. 选择 `mainproject` 模块运行到设备
3. 首次启动时按提示授予相机、麦克风、通知、悬浮窗、无障碍和屏幕采集相关权限
4. 在设置里确认信令地址

常用地址：

- 模拟器：`ws://10.0.2.2:3000/ws`
- 真机：`ws://<宿主机局域网IP>:3000/ws`

## 主应用流程

主应用当前支持的体验链路是：

1. 子女端创建协助请求
2. 生成带签名的 Deep Link / token
3. 长辈端打开链接进入验证
4. 双方完成视频核验
5. 长辈端授权后进入远程协助
6. 子女端发起远程操作，长辈端执行屏幕采集和无障碍控制

## 常见问题

### 1. 模拟器连接不上服务端

- 确认后端已经启动
- 确认信令地址是 `ws://10.0.2.2:3000/ws`
- 检查防火墙是否拦截了 3000 端口

### 2. 真机无法加入房间

- 把信令地址改成宿主机局域网 IP
- 确认手机和电脑在同一局域网
- 确认电脑本机 3000 端口可访问

### 3. 看不到视频或麦克风没声音

- 检查相机和麦克风权限
- 检查设备是否占用了摄像头
- 确认浏览器或其它 App 没有独占音频设备

### 4. 远程控制没有生效

- 先打开无障碍服务
- 先授予屏幕采集权限
- 确认目标端和控制端在同一房间
