# 家庭远程协助App - 零绑定安全版产品方案

## 一、核心理念调整

**传统方案**：先绑定 → 后协助（需要长辈配合完成绑定配置）

**新方案**：随时发起 → 短信验证 → 视频确认 → 临时授权（无需任何预先配置）

### 核心原则

1. **零预设**：长辈无需注册、无需登录、无需绑定，手机号即身份
2. **一次性授权**：每次协助独立授权，用完即失效
3. **真人验证**：视频通话是唯一的身份确认方式
4. **全程留痕**：所有操作可追溯，形成完整证据链

### 3.2 短信拉起模块（核心入口）

| 功能点 | 描述 | 安全考量 |
|--------|------|----------|
| 短信发送 | 系统自动发送，显示子女姓名 | 发送方为系统，但内容含子女名 |
| Deep Link | 唯一链接，含加密参数 | 防篡改、防重放 |
| 无App引导 | 无App时跳转下载页 | 确保能完成协助 |
| 链接过期 | 5分钟有效期 | 防止链接被滥用 |
| 一次性使用 | 点击后立即失效 | 防止重复使用 |

**短信内容设计**：
```
【家庭协助】您的子女 张三 正在请求帮助您操作手机，请点击链接验证身份：
https://help.yourdomain.com/r/abc123xyz

（链接5分钟内有效，如非本人操作请忽略）
```

**Deep Link参数结构**：
```
https://help.yourdomain.com/r/{requestId}

requestId 包含以下加密信息：
- 子女ID
- 子女姓名
- 父母手机号
- 时间戳
- 随机数
- 签名（防篡改）
```

## 四、安全机制汇总

### 4.1 身份认证层（无需预绑定）

| 机制 | 描述 | 防什么 |
|------|------|--------|
| 短信拉起 | 通过子女发起，短信发送至父母手机 | 防止随机连接 |
| 视频验证 | 真人出镜确认 | 防止冒充身份 |
| 动作验证 | 要求子女做指定动作 | 防照片/视频冒充 |
| 手机号校验 | 子女端需已认证手机号 | 防止匿名发起 |

### 4.2 操作控制层

| 机制 | 描述 | 防什么 |
|------|------|--------|
| 金融App黑名单 | 自动暂停控制 | 防止转账诈骗 |
| 密码输入检测 | 画面模糊化 | 防止密码泄露 |
| 点击频率限制 | 1秒最多3次 | 防止恶意刷屏 |
| 连接时长限制 | 最多30分钟 | 防止长时间控制 |

### 4.3 监督审计层

| 机制 | 描述 | 防什么 |
|------|------|--------|
| 定时抓拍 | 每30秒拍照 | 形成证据链 |
| 全程录音 | 双向语音录制 | 记录沟通内容 |
| 操作日志 | 记录每次点击 | 操作可追溯 |
| 紧急断开 | 一键切断 | 长辈可随时终止 |

### 5.2 接口概要

| 接口 | 方法 | 用途 | 安全要求 |
|------|------|------|----------|
| `/api/help/request` | POST | 发起协助请求，发送短信 | 子女端Token校验 |
| `/api/help/verify` | POST | 视频验证通过，建立会话 | 请求ID+长辈确认 |

| `/api/logs/upload` | POST | 上传安全日志 | 会话ID校验+加密 |

### 5.3 Deep Link生成与验证

**生成逻辑**（服务端）：
```
function generateDeepLink(childId, childName, elderPhone) {
    const requestId = generateUUID()
    const payload = {
        rid: requestId,
        cid: childId,
        cname: childName,
        phone: elderPhone,
        exp: now() + 5 * 60 * 1000  // 5分钟过期
    }
    const signature = hmacSHA256(JSON.stringify(payload), SECRET_KEY)
    const token = base64Encode(JSON.stringify(payload)) + "." + signature
    return `https://help.yourdomain.com/r/${token}`
}
```

**验证逻辑**（长辈端打开时）：
```
function verifyDeepLink(token) {
    const [payloadStr, signature] = token.split(".")
    const expectedSig = hmacSHA256(payloadStr, SECRET_KEY)
    if (signature !== expectedSig) return { valid: false, reason: "签名无效" }
    
    const payload = JSON.parse(base64Decode(payloadStr))
    if (payload.exp < now()) return { valid: false, reason: "链接已过期" }
    
    return { valid: true, requestId: payload.rid, childId: payload.cid, childName: payload.cname }
}
```

## 六、异常场景处理

| 异常场景 | 处理方案 |
|----------|----------|
| 短信链接过期 | 提示“链接已过期，请让子女重新发起” |
| 长辈无App | 跳转下载页，下载后自动打开Deep Link |
| 视频验证超时 | 自动断开，提示“验证超时，请重新发起” |
| 网络断开 | 自动重连3次，失败后结束会话，保存已有日志 |
| 长辈误触断开 | 弹窗确认“确定要断开吗？”，防止误操作 |
| 子女端异常退出 | 长辈端提示“连接已断开”，自动停止共享 |
| 检测到敏感页面 | 自动暂停远程控制，提示“已进入安全模式” |
| 连接时长超限 | 提示“已达到30分钟安全时限”，自动断开 |
| 同一手机号并发请求 | 后发请求覆盖前一个，前一个链接失效 |

## 九、方案对比

| 维度 | 传统绑定方案 | 新方案（零绑定） |
|------|-------------|-----------------|
| 长辈前置操作 | 需要注册、登录、扫码绑定 | **无需任何操作** |
| 首次使用门槛 | 高（需长辈配合） | **低（仅需点短信链接）** |
| 身份验证方式 | 绑定关系 | **每次视频验证** |
| 安全性 | 依赖绑定关系不被盗 | **依赖视频确认，更直观** |

## 十一、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 短信被拦截 | 不法分子获取链接 | 链接5分钟过期+一次性使用+签名校验 |
| 视频验证被AI换脸 | 冒充子女 | 增加动作指令（挥手、转头等） |
| 长辈误点链接 | 发起无效请求 | 验证界面需主动点击“接受”才生效 |
| 本地证据被篡改 | 证据无效 | 加密存储+可选云端备份 |
| 无障碍服务被禁用 | 无法远程控制 | 引导用户开启，提示功能受限 |

## 十二、总结

本方案的核心创新：

1. **零预先绑定**：长辈无需任何配置，子女输入手机号即可发起
2. **短信拉起**：通过可信渠道（短信）传递请求，信息来源可追溯
3. **视频验证**：每次协助前强制视频确认，长辈亲眼确认操作者身份
4. **全程监控**：定时抓拍+全程录音，形成完整证据链
5. **金融拦截**：敏感页面自动暂停操控，阻断诈骗核心环节

**最大的优势**：长辈的体验极简——只需点击短信链接、看视频确认、点接受，三步完成，无需任何注册和配置。同时安全性不降反升，因为每次协助都是独立验证，不留持久授权通道。
